Key Pillars

Designed for Public Trust & Accessibility

Every component is engineered to serve non-literate and semi-literate rural citizens cleanly and safely.

LangGraph 5-Node Agent

Splits reasoning into Extract, Retrieve, Evaluate, Chain, and Compose steps to guarantee strict numerical eligibility checking without LLM hallucination.

Vision Document Scan

Processes Aadhaar cards and income certificates via Groq Llama 4 Vision OCR, auto-filling parameters so users never have to type manually.

Option A Ephemeral Privacy

Complies with India's DPDP Act. PII is stored only in ephemeral memory caches and is purged automatically, leaving zero trace in permanent SQL tables.
